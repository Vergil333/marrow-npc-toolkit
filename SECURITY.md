# Security policy

Do not attach proprietary game or character files to a public issue.

For a suspected vulnerability that could expose local files, execute arbitrary
editor code unexpectedly, or publish private assets, use the repository's
[private vulnerability report](https://github.com/Vergil333/marrow-npc-toolkit/security/advisories/new).
The repository owner must enable GitHub Private Vulnerability Reporting before
the first public release. Do not put exploit details or private files in a
public issue.

Only the newest tagged preview and its documented official-SDK environment are
supported while the project remains below version 1.0. Compatibility failures
after a BONELAB, Marrow SDK, or Unity update should be reported as compatibility
issues rather than security issues unless they cross a trust boundary.
